# ECP-0001：Windows 本机功能开发优先

Status: accepted
Date: 2026-09-07
Authorization: 用户在完整方案回顾后明确要求“完成方案重构”。
Scope: 方案、阶段、验收、任务依赖和开发格式兼容的适用范围；本次不执行功能实现或远端状态变更。
Decision Owner: 用户；各实施任务的责任人在认领时明确，本提案不授予 Release Owner 权限。

## 决定

第一目标是 Windows 本机功能完成。R00 退出状态为 Development Ready；R01–R12 按能力增量实现，完整 Windows 功能在 W6 验收；最低 OS、Linux、多设备、独立 VM、第三方复现和 Stable 晋升归 R13/W7。

Windows 宿主的实际 OS/build 必须如实记录。开发验收不以 Windows 11 虚拟机为前置；宿主结果不冒充最低 Windows 11 认证。新增数据、软件、缓存、临时文件和日志在 E 盘；不为开发门槛继续扩展镜像或云资源。

既有源码、仓库拓扑、工具链版本、Build Identity 算法、锁文件与不可变历史保留。原 Smoke Targets 不变成产品占位实现。未通过的认证记录为延期，原成功证据不改写。

## 取舍与适用优先级

原方案选择在任何语言功能之前完成双平台可复现发布；当前选择先证明 Windows 的真实产品功能，再认证支持范围。代价是早期不承诺最低 OS/其他平台，跨平台风险在后续认证暴露；通过固定工具、基础路径可移植性及持续正确性测试降低返工。

本提案对以下旧 ADR 的阶段和承诺范围作明确修订；其未涉及规则继续有效：

| 旧决定 | 本次调整 | 保留部分 |
|---|---|---|
| ADR-0002 可复现离线边界 | 双 VM、Linux 最低平台与跨平台独立 job/comparator 认证后置；R00 保留同宿主两个 clean producer 与 build-free comparator，均可在 E 盘独立目录运行 | 发布 Build Identity、完整 repro 证据、无隐式输入、发布隔离和 PR secret 边界 |
| ADR-0003 产品/契约版本 | R00 不产生首次 Stable；未承诺兼容的开发格式可原子更新，不承担两个稳定 minor 迁移窗口 | 产品/契约版本独立、语义/Schema Hash 变化需版本决定、已受支持版本的兼容承诺 |
| ADR-0007 Tier 1 基线 | 最低 Windows/Linux 作为 W7 待验证认证基线；当前 Windows 宿主可作开发平台 | target 身份、SDK/CPU 规则及实际认证前不得宣称支持 |
| ADR-0008 Owner 晋升 | 阶段关闭指发布阶段，Development Ready/Windows Functional Complete 不要求 Promotable/Stable | Owner、不可变 tag/snapshot、default 提交点、回滚与证据规则 |

架构保留最终功能边界，Roadmap 定义阶段，工程章程和 R00 spec 定义本机工程验收。历史归档与旧任务评论仅作 provenance，不能重新引入已迁移的开发阻塞。遇到其他未被本提案修订的冲突需具体处理，不以“Windows 优先”取消正确性要求。

## Source 与契约

可维护源码、精确实际消费来源、许可证/NOTICE、真实构建输入和消费者始终必需；未使用来源不预建 fork。内部实现继续通过正式接口测试。

开发格式变更必须有规范版本决定、producer/consumer 同步和旧缓存失效；明确拒绝不支持的格式。已发布且承诺支持的版本继续按原兼容窗口迁移。实际 schema 结构或 gate 的代码变更另开能力票，不在本次添加虚构已实现字段。

Reflection 首次实现后，对相同源码、目标、选项、工具和 schema 在独立输出目录重复生成规范摘要；相关输入变化需可检测。目标相关布局不能要求跨目标字节相同。R00 无 Reflection 时记不适用，空 Contract Set 不作替代。

## 验收与迁移

- R00 spec v2 的 W00-01–W00-10 是本机工程门。
- Roadmap W0–W7 与 G1–G6 保留最终功能，能力依赖无 R06/R07 整阶段循环。
- 工作区原 R00 17–19 保留未完成事实并链接后继任务；01–16 的既有结果不撤销、不自动重跑。
- 单独实施票负责实际开发入口/CI 对齐，本次文档修改不改变程序行为、required checks 或远端权限。
- 新验收必须运行后才可标记 Development Ready；不因迁移旧票而产生成功、Stable 或发布授权记录。

## 备选方案、安全与回滚

备选方案是保持原 R00 全平台发布闭环，或只做 Windows 演示并删除最终功能。前者不符合当前开发优先级，后者丢失完整产品目标；本提案选择完整功能保留、认证分阶段。

本次不改 Build Identity 算法、锁文件或正式 contract schema。开发格式兼容政策只影响未来未承诺支持的同仓版本；落实到代码时须有版本/缓存失效和负例。源码来源、许可证和 PR 安全不降低，不新增凭据、网络出口或外部服务。

验证是本地文档/链接/验收编号/任务依赖检查，不是产品或发布成功证据。旧规格和任务记录保留可回溯。若未来决定改变阶段，另以 ECP 明确变更并迁移任务；不能移动 tag、改写 snapshot，或把延期事项倒填成通过。此次文档变更的回退也仅限文档/任务，不触发历史切换命令或环境清理。
