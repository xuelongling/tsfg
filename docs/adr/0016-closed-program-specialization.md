# 在明确编译闭包内特化泛型并保留泛型包定义

用户于 2026-09-30 接受 R03 Q5：全程序特化以明确的 Compilation Closure 为范围，覆盖模块初始化、宿主导出/回调、热更与内核入口及其依赖和可达实例；泛型预编译包保留自有、版本化、可在编译期继续特化的类型化定义，最终执行 Core IR 只含具体实例。相对于只保存有限预生成实例或引入运行时泛型，此选择兑现消费方新增合法类型实参的能力，代价是维护类型化定义与官方前端之间的正式适配、来源和版本契约；不把上游 AST/Checker 会话对象作为包数据。

R03 负责定义表示与特化，R02b 提供必要类型事实，R04/R12 负责实际交换和包消费；当前源码尚未证明泛型包脱离原源码的实例化闭环，该能力必须通过正式实现和验收补齐，不能由本决策推定已经实现。取舍和验收边界见 [R03 规范](../r03-ir-normalization.md)。
