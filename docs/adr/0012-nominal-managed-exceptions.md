# 受管异常限定为名义异常对象

2026-09-09 路线修正：用户要求默认沿用官方 TypeScript 前端及语言规则，仅客制化特殊且必需之处。此额外抛出值域限制尚未证明为 lowering 或架构所必需，因此停止作为实施约束；以下仅保留原始决定和理由。架构规定的异常不跨 Zig ABI、不进入内核仍有效。

R01 Q36 已获用户确认：受管异常只接受单一名义异常基类及其受管派生对象，catch 使用 unknown 静态视图并经收窄访问，重抛保留对象身份；不接受任意标量或任意普通对象。相对于允许任意抛出值，这牺牲部分熟悉的 TS/JS 写法，使异常通道不依赖一般动态值或隐式装箱，并保持它与 trap、Execution Abort 和 Zig ABI 失败边界的区分。记录日期：2026-09-09；基类接口、展开与边界转换另在语言契约中细化，不据此预建异常框架。
