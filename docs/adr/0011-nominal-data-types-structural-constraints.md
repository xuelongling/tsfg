# 值类型与组件保留身份，普通类型关系沿用 TypeScript

值类型与组件具有明确身份，相同布局不自动互换；它们不继承，保留固定布局及组件身份边界。普通 class 支持规定的单继承、方法覆写与 GC 对象身份，其源码赋值兼容性及 interface/类型工具的编译期关系沿用 TypeScript。记录及收口修订日期：2026-09-09。

最初 Q23 将所有普通 class 一并规定为名义赋值；用户明确默认复用官方 TS、只保留必要差异后，该过宽部分撤回。GC 对象身份和固定布局并不能单独证明有必要拒绝普通 TS 结构赋值。保留值/组件身份的代价是这类特殊数据不能仅凭形状互换；普通类无需承担同样的额外限制，也不因此引入动态对象、运行时 interface 对象或隐式装箱。
