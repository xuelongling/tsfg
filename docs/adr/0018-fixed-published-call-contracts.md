# 以固定发布调用上界隔离实现效果变化

用户于 2026-09-30 接受 R03 Q9：可替换函数保留真实推导摘要，同时向调用方发布固定保守的 Published Call Contract；新实现必须满足既有上界，效果收窄可以保持契约及 hash 不变，超界扩展须重分析调用方并协调更新。相对于把每次函数体摘要直接作为兼容身份，此选择允许安全收窄而不使无害实现变化触发契约替换，代价是调用方、内核和并行分析继续采用发布上界，不能借当前实现的更窄效果获得未经约束的优化。

现有签名/效果等 exact-match seam 继续比较发布契约身份，不改为方向性 hash 握手。R03 负责推导、满足性检查及依赖，R04/R09 负责交换和发布；不可分析原生调用的输入另由已接受 Q8 的 Host Semantic Contract 明确实现身份与信任边界，源码注释和能力授权都不能代替它。详见 [R03 澄清记录](../r03-ir-normalization.md)。
