# 活跃 Span 借用保持容器结构稳定

用户于 2026-09-30 接受 R03 Q11：活跃 Span/ReadSpan 期间，任何别名不得改变所借容器的长度、容量，或释放、转移其缓冲区；按真实最后使用点结束借用，之后恢复结构修改。相对于只在某次扩容搬家时失败或用动态拥有者检查放行未知别名，此选择提供与偶然容量和分配器结果无关的静态借用契约，代价是部分物理上不会失效的结构变更也受约束；分析须支持真实别名、跨调用摘要和最后使用点，不能全拒绝或按整函数过度延长借用。

普通 Array 共享身份不改成 move-only、复制或快照；串行已有元素写入仍可对视图可见，ReadSpan 不构成全局冻结或 Rust 独占政策。Q6 的强制静态安全要求及 Q8/Q9 调用契约继续适用，证明不足时明确拒绝相关借用操作，不新增动态兜底例外；这不等于要求全部普通 Array 索引边界静态可证。详见 [R03 澄清记录](../r03-ir-normalization.md)。
