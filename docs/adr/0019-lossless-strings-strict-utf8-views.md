# 无损字符串表示与严格 UTF-8 视图分离

用户于 2026-09-30 接受 R03 Q10：普通 tsfg String 保持既定 TS 码元行为，内部采用 canonical WTF-8 无损保存，包括孤立代理码元；StringView 是严格 UTF-8、字节长度的受控借用，不能严格输出时显式失败，有损替换仅由调用方明确选择。相对于任意 UTF-16 内部存储，此选择保留合法 Unicode 文本的 UTF-8 字节常见路径；代价是码元索引、切片、排序和代理对拼接均需正式语义实现，不能把字节操作直接当成文本操作，也不能把 WTF-8 冒称标准 UTF-8 交换编码。

严格 UTF-8 单独作为普通字符串值域会丢失合法 TS 值；自动替换或拒绝孤立代理码元均未被采用。编码一致不证明 ABI 借用安全，Runtime 仍须保证来源保活、字节地址稳定和不得越期保留；源编码、逻辑字符串和宿主视图分别验收，不承诺任意 managed String 自动零复制跨界。详见 [R03 澄清记录](../r03-ir-normalization.md)。
