# 用后端无关语义预算约束执行

R01 Q10 已获用户确认：采用后端无关的 Semantic Fuel 和活动调用深度，使 VM/AOT 共用语义计费点；物理指令、内存和宿主时限继续单独受限，不能把时限终止当语言 oracle 的正确结果。Q16 又确认首批函数入口和每次 while 条件求值前各耗 1 fuel，优化保留逻辑事件；具体边界见 R01 规范，不将后端指令数写作语言预算。记录日期：2026-09-09。

按各后端实际指令数独立计费较易实现，却会让优化、内联或后端切换改变程序在哪一步耗尽语义预算。统一语义预算选择了可比较的执行边界，代价是 AOT 和优化流水线必须保留必要检查及语义计费信息；它不要求两后端具有相同机器指令数，也不取代物理资源保护。
