# Private nullable cold admission

This Runtime module implements the future cold-consumer checks already specified by the frozen TSFGNUL1/version1 descriptor (JCS hash30ad00db…). It is an explicit private-format namespace at bytecode.nullable. It does not alter formal TSFGTBC0/wire9, the shared scalar type codes1–13, Runtime evaluation, Host ABI or the contract registry.

The interface is load(allocator,bytes), snapshot/inspect/serialize(handle), and unload(handle). The distinct opaque VerifiedNullableModule cannot be passed to the existing VM VerifiedModule interface. Snapshot nested slices are readonly and live only until unload; input bytes are copied and owned. Loading a packet does not initialize or execute a module. Role0 identifies the sole scalar-signature entry, which need not be function0; internal roles remain unavailable for host selection.

Decode/identity owns exact header/schema/integrity, reserved fields, bounded strings and counts, target/layout, source ranges, candidate entity hashes, complete roles and dense declarations. Before count-based wire-table allocation it checks count against remaining bytes divided by a structural minimum: function141B, block4B, parameter4B, instruction16B (existing operand groups use2B). The function minimum includes its nonempty name, fixed prefix and one block/instruction; extension fields only add bytes. No untrusted count multiplication is needed. CFG independently checks operands and dominance, exact call/return/phi types, all block reachability, entry/loop fuel placement and cycles that bypass loop events. A separate finite monotone worklist then proves possible tags for immutable SSA identities. Tags0/1/2 mean present/undefined/null; set bits1/2/4 encode their possible membership. Calls reset to the callee declaration; only a direct tag-test condition refines its exact operand identity. Local definitions are cleared at block transfer, destination phi facts arise only from filtered edge operands, and empty facts never justify get/retype.

Packet bytes are limited to1MiB, functions512, parameters64, registers4096, blocks256 and instructions8192. Products are checked before proof allocation: at most1048576 cells and three inserted tag bits per cell. A fixed-size pending ring has at most one item per block. CFG reachability/dominator updates and fuel-cycle elimination are finite monotone algorithms. Per-function verification scratch is freed immediately. All decoding and proof stages must finish before the single opaque publication point; any rejection or allocation failure releases owned temporary storage.

Input/source digests are claimed content metadata used for candidate entity consistency; they are not authenticated Source provenance or the current BuildIdentity.

The actual1721B input is retained old20c C++ output, not a new Source/execution result. Its independent whole expected model comes from the original hand-authored five declarations/39 operation rows and identity formulas. The original FIRST/expected bytes are frozen before production implementation; real BASE RED/current GREEN use exactly those frozen bytes. Deep mutations repair transport hashes, so tag/dominance failures cannot hide behind integrity rejection. Independent synthetic wire data explicitly carries no Source/producer/execution authority: it covers a fuel-metered cycle, unmetered cycle, empty and stale proof cases, actual512-function and4096-register/256-block/1048576-cell maxima, all13 scalar codes/raw NaN bits, and entry-not-first with a Unicode logical path. The8192-instruction ceiling is not claimed as an independently reachable positive under stricter register/block constraints.

The module is included in the real Runtime source staging list and exact Build Input Set. The old test reader is not used by production. No root/VM/Host/bridge/Source/native-probe import or execution is introduced. Parent20b/M20/formal Runtime/VM/RF acceptance remains open; all concrete platform safety refusals remain stopped.
